# Security reports

Report vulnerabilities privately to miroslav@miroslavbakos.com. Include the
version, impact and reproduction steps using fictional data. Do not publish
credentials, customer data or an exploitable production URL in an issue.

Please allow time to investigate before public disclosure. This spare-time
project has no guaranteed response time or supported-version schedule.

Use application login, keep backups private, and avoid exposing the application
port publicly. Install updates and review your marketplace permissions regularly.
